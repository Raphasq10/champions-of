Tabela de Breakpoints Responsivos

Dispositivo / Breakpoint Medida Variável CSS Comportamento esperado no Layout
Desktop Largo 1440px --breakpoint-desktop Exibe o container alinhado centralmente com preenchimento lateral padrão de 15% (30% total).
Tablet Landscape 1024px --breakpoint-tablet-l Menu principal encolhe levemente. Grids de 4 colunas podem passar para 2 colunas se necessário.
Tablet Portrait 991px --breakpoint-tablet-p O menu superior colapsa para o botão hamburguer. O padding lateral é ajustado para 24px.
Celular Landscape 767px --breakpoint-mobile-l O layout de colunas paralelas se transforma em blocos 100% verticais (Flex direction: column).
Celular Portrait 575px --breakpoint-mobile-p Paddings laterais reduzem para 16px para maximizar a área visível do celular. Títulos reduzem o tamanho.
